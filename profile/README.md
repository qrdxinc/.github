# QRdx

Open-source QR codes for people and developers.

- **[qrdx.dev](https://qrdx.dev):** design a QR code with patterns, frames, logos and print-ready PDF and EPS exports, free with no signup. Sign in for dynamic codes you can edit after printing, hosted pages and scan analytics.
- **For developers:** the `qrdx` React library, the `@qrdx/cli` command line, a REST API, an MCP server, a shadcn/ui registry, and plugins for Chrome, Figma, Raycast and Canva. Start at the [docs](https://qrdx.dev/docs).
- **Open source:** the app is AGPL-3.0 and self-hostable; the plugins are MIT. Code: [github.com/bucharitesh/qrdx](https://github.com/bucharitesh/qrdx).

Security reports: [support@qrdx.dev](mailto:support@qrdx.dev).
